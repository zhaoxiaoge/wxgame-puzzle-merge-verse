# 益智合成小宇宙

滑动、合并、进化——从一粒星尘到整个宇宙。经典 2048 玩法的休闲益智小游戏，纯原生 JavaScript + Canvas 实现，无引擎、无框架、无后端，离线可玩。

## 玩法

在 4×4 棋盘上向四个方向滑动，相同数字的方块碰撞后合并翻倍（两个 2 合并为 4），每次有效移动后随机生成一张新牌。合成出 2048 即达成目标，可继续挑战 4096、8192 等更高数字；棋盘填满且无法合并时本局结束。

## 功能特性

- **多主题系统**：星宇宙 / 经典 2048 / 果园 / 喵喵 / 极简暗黑 五套内置主题，一键切换
- **自定义主题**：上传图片裁剪后自动生成配套配色（图片主题），或自定义各档位名称（词条主题），支持棋盘背景图与配色基调选择，可随时编辑
- **每日挑战**：每天固定种子生成同一棋盘，全网玩家相同开局；纯净模式（无道具）保证公平，记录当日最高分、连胜与累计完成天数
- **辅助道具**：撤销、消除、复活三种道具（观看激励视频获得，每局各限 3 次）
- **战绩统计**：按主题记录最高分、总局数与历史最高方块，可视化展示
- **成就里程碑**：首次合成 128 / 512 / 1024 / 4096 等高阶方块时获得成就提示
- **本地存档**：自动保存进行中棋局与全部数据，退出后随时恢复，无后端、无账号
- **音效与震动**：合成音效反馈，均可开关

## 技术栈

- 纯原生 JavaScript（CommonJS 模块），无游戏引擎、无 npm 依赖
- Canvas 2D 手绘全部界面与动画
- 数据全部本地存储（`wx.setStorageSync` + 本地文件），不采集任何用户数据
